## 🇬🇧 English

### About the Project

Expense Tracker is a mobile-friendly expense tracking application developed with Ionic and Angular. Originally created as a coursework project for a mobile application development class, it was subsequently refined with a modern user interface, a glassmorphism-inspired dark theme, and improved TypeScript code structure.

The project demonstrates the practical application of mobile development concepts, component-based architecture, and client-side data persistence.

### Key Features

- **Expense Management:** Add expenses with a name, amount, and category.
- **Category Organization:** Organize expenses into categories such as Food, Bills, and Other.
- **Swipe-to-Delete:** Delete expense items by swiping left using Ionic sliding components.
- **Expense Summary:** View total spending and transaction counts through dynamically updated summary cards.
- **Local Data Persistence:** Store expense data in browser `localStorage` to retain it across page reloads and browser sessions.
- **Modern User Interface:** A dark-themed, glassmorphism-inspired design styled with SCSS.
- **Type Safety:** Use TypeScript to improve code structure and maintainability.

### Tech Stack

- **Framework:** Ionic, Angular (Standalone Components)
- **Programming Language:** TypeScript
- **Styling:** SCSS, Ionic CSS Variables
- **Icons:** Ionicons
- **Data Storage:** Browser `localStorage`

### Getting Started

#### Prerequisites

- Node.js and npm
- Ionic CLI (optional, depending on the command used)

#### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/ismail7eren-tech/harcama-takip-uygulamasi.git
   cd harcama-takip-uygulamasi
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npx ionic serve
   ```

   Alternatively, if the project defines a suitable start script in `package.json`, you can run:

   ```bash
   npm start
   ```
